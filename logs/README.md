# Logs

Sanitised game, launcher, anti-cheat and platform logs used as research evidence.

## Areas

- `game/` — game runtime logs such as `PortalWars2.log`
- `launcher/` — launcher-related logs
- `anticheat/` — RedKard / anti-cheat observations and logs
- `proton/` — Linux / Proton runtime and Steam-relevant logs
- `networking/` — derived network log summaries where applicable

## Reading order

Prefer the relevant [session record](../sessions/) or [finding](../findings/) first. Log files are evidence supporting those records, not standalone architectural conclusions.

## Handling

Published logs should be sanitised to remove unnecessary account identifiers, local paths, IP addresses and other personal information. Preserve stable placeholders where relationships between observations matter.

Do not upload or publish authentication tokens, cookies, credentials, proprietary game files or unrelated personal logs.
