# Builds

Historical and current build metadata. Prefer manifests, IDs and hashes over redistributing proprietary game files.

## Areas

- `metadata/` — build metadata
- `manifests/` — manifest identifiers
- `hashes/` — executable and file hashes
- `notes/` — build-specific notes

See [build tracks](../BUILD_TRACKS.md) for the SGAR/current and June 6, 2025 SG2 separation.
