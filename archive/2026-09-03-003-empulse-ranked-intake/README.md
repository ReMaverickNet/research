## Scope labels

- **EMPULSE** — directly observed in EMPULSE evidence.
- **SGAR** — existing Splitgate: Arena Reloaded evidence.
- **SHARED** — demonstrated commonality between the games.
- **CROSS-GAME INFERENCE** — comparison-based hypothesis requiring further confirmation.
- **UNKNOWN** — evidence does not establish the relationship.

Raw source evidence is deliberately not committed here.
