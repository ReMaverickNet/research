# EMPULSE / SGAR scope labelling

To keep the shared-backend research understandable, EMPULSE material is explicitly classified:

- **EMPULSE** — observed only in EMPULSE evidence.
- **SGAR** — existing Splitgate: Arena Reloaded baseline evidence.
- **SHARED** — demonstrated commonality, not merely similar naming.
- **CROSS-GAME INFERENCE** — comparison-based hypothesis awaiting direct cross-game confirmation.
- **UNKNOWN** — evidence does not establish ownership or equivalence.

Repository findings about EMPULSE should use the label in the title/intro or a clearly scoped section. `NETWORK.md` should use the same convention when describing mixed-game architecture.
