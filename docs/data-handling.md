# Data handling

Research artefacts can contain personal information and proprietary material. Treat raw captures as sensitive until reviewed.

## Before publishing

- Remove Steam credentials, tokens, cookies and authentication data.
- Redact personal/home IP addresses and player-identifying information.
- Remove private Discord messages or support material without permission.
- Do not upload game executables, DLLs, packaged Unreal assets or other substantial proprietary content.
- Keep raw/private captures outside the repository when publication is not appropriate.

## Prefer publishing

- Timestamps
- Build/depot/manifest identifiers
- File sizes and SHA-256 hashes
- Redacted logs
- Packet metadata and protocol observations
- Reproduction steps
- Analysis and conclusions linked to evidence
